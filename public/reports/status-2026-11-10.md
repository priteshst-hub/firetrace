The public data-access gate passes for the existing MODIS C6 / VIIRS S-NPP C2 descriptive experiment. Exact MODIS C6.1 observations and coverage-aware harmonization remain unfinished. No credentials were requested, no authentication attempted, no messages sent and no UI built.

## Actual study data

Australia-country membership intersected with bbox 140,-39,154,-29; inclusive UTC dates 2019-09-01 through 2020-03-31 (213 days).

| Measure | MODIS C6, source 6.03 | VIIRS S-NPP C2, source 2 |
|---|---:|---:|
| Selected source observations | 106,390 | 569,166 |
| Baseline type/confidence retained | 97,185 | 542,727 |
| Exact duplicate selected rows | 0 | 0 |
| Days with source detections | 210 | 212 |

Both series peak in December 2019. The baseline's 10 km UTC date/day-night occupied-unit Jaccard overlap is 48.65%; 5 km and 20 km give 44.06% and 50.77%. This is descriptive overlap, not accuracy or calibration. VIIRS's larger count is not a conversion coefficient.

No MODIS rows on 2020-02-09, 2020-03-05 or 2020-03-06; no VIIRS rows on 2020-02-09. These are missing-detection dates, not proven fire-free or satellite-outage dates.

## Authentication and scientific blockers

| Route or requirement | Observed result | Consequence |
|---|---|---|
| Annual 2019/2020 MODIS and S-NPP country ZIPs | Public range downloads work | Current observations reproducible without credentials |
| Custom FIRMS archive | Login page offers Earthdata or email code | Exact C6.1 custom extract not retrieved through this route |
| FIRMS Area API | Documentation requires MAP_KEY; 1–5 days per request | No keyed data request attempted; not evidence of a server rejection |
| CMR collection/granule metadata | Public JSON, full inventory retrieved | Exact products and intersecting historical granules verified |
| Sample MOD14/MYD14 V061 and VNP14IMG V002 science files | Three HTTP 401 responses after Earthdata redirect | Full fire masks and QA not obtained through these tested links |
| Long-term calibration | Only seven-month event extract processed | No transferable fitted harmonization model claimed |

An authenticated route is an observed blocker on these tested links, not proof that every possible NASA distribution route requires authentication. We have not verified a public exact-C6.1 observation alternative. No claim is made that CMR metadata substitutes for science data.

## Reproduce

From the workspace, using Python standard library:

```
python3 firetrace-data-gate/audit.py
python3 firetrace-data-gate/metadata.py
python3 firetrace-data-gate/validate.py
python3 firetrace-analysis/analyze.py
python3 firetrace-analysis/sensitivity.py
```

retrieve.py is the existing downloader for the four original Australia members; rerunning it downloads and replaces those files and their provenance. It is unnecessary for verification while the current hashes and live ZIP CRCs match.
